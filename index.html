Evaluation scope and configuration details

The common CAD protocol uses frozen reader r010. Topology measures supported relations in the matched scope; layout measures local geometry. Valid counts describe evidence availability, not engineering approval. The review gallery and scored CAD corpus are versioned separately.

The DeepSeek-backed PFD-Agent configuration used model grouping on 6 tasks and local source-graph fallback on 44. These results compare supplied configurations; they do not isolate the API backbone alone.
