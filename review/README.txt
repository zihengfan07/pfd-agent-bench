PFD 五案例专家审阅包

1. 先将整个 ZIP 解压到一个普通文件夹，不要直接在压缩软件中打开。
2. 双击“开始审阅.html”，用 Edge、Chrome 或 Firefox 打开。无需安装 Python、AutoCAD，也不需要 API 或联网。
3. 在右上角填写姓名或代号。左侧切换案例，按图纸编号或 Aspen 原编号搜索设备、流股。
4. 点击设备查看关联流股；点击流股查看上下游和跨页去向，点击页号即可跳转。
5. 点击“标注这个设备/流股”，或使用“框选标注”圈出问题区域。填写问题类别、影响程度和建议后，点击“保存意见”。
6. 审阅完成后，点击右上角“导出意见 JSON”，将下载的 JSON 文件发回；也可以另导出 CSV，方便表格阅读。图纸不必再次发回。
7. 继续审阅时使用同一浏览器打开同一个 HTML 文件；换电脑、移动文件夹或清除浏览器数据前，先导出 JSON。再次打开后点击“导入意见”恢复。

提示：意见先保存在当前浏览器，缓存不是备份；建议每次审阅后导出 JSON。浏览器若禁止本地保存，页面会提示，此时请立即导出。导出的文件一般在“下载”文件夹。

包含 5 个案例，共 111 页图纸、1319 个设备节点、2023 条流股。可点击“案例说明与下载”查看输入 XML 和原生 PDF/DWG/DXF。
图纸是本轮模型生成结果，供您指出分组、流程连接与图面表达的问题。案例原状态、来源和许可见页面及 DATA_SOURCES.md。
